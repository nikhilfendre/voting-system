Demo Guide (2 minutes)

  1. Election is already set up with 3 candidates and 5 voters.
  2. Go to Cast Your Vote — enter a Voter ID like CS102, pick a candidate, vote. A new block is mined in front of you.
  3. Try voting again with the same ID — the system rejects it.
  4. Open Blockchain Explorer — see the blocks, hashes and links. Click Verify Chain, then try the Tamper Test.
  5. Admin closes the election (Admin Panel, PIN 1234) — winner appears in Results.
